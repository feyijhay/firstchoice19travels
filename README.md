# Travel Agency Website

A modern React-based travel website with a clean white and blue design.

## Pages
- Home - Hero section with featured services
- Destinations - Browse popular travel destinations
- About - Learn about the travel agency
- Contact - Get in touch via contact form

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

```bash
npm run build
```

## Tech Stack
- React 18
- React Router 6
- CSS3
